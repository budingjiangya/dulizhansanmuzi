# 产品推荐博客网站｜完整技术方案说明书

## 一、项目概述

**项目名称**：产品推荐博客站点（前台内容门户 + RBAC 后台管理系统）
**业务需求**

1. 前台门户：首页卡片列表展示产品 / 博客推荐；封面两种模式：多张图片悬浮自动轮切、短视频‑后端随机抽帧作为静态封面，鼠标悬浮静音预览短视频；点击卡片跳转文章详情页。
2. 管理后台：账号登录 (JWT 鉴权)；RBAC 角色权限（超级管理员 / 内容编辑）；管理员账号维护；登录日志记录；管理员密码重置；博客文章完整 CRUD、资源上传、首页推荐标记、上下架、排序；富文本编辑正文。

> 
> 定位：内容展示型站点；后期可扩展标签、搜索、访问统计。

## 三、数据库模型 (Prisma Schema)

```
generator client {
  provider = "prisma-client-js"
}
datasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")
}

model AdminUser {
  id          Int      @id @default(autoincrement())
  username    String   @unique @db.VarChar(64)
  password    String   @db.VarChar(128)
  realName    String   @db.VarChar(64)
  roleId      Int
  status      Int      @default(1) //1启用，0禁用
  lastLoginAt DateTime?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  role       AdminRole        @relation(fields: [roleId], references: [id])
  loginLogs  AdminLoginLog[]
}

model AdminRole {
  id          Int    @id @default(autoincrement())
  roleName    String @db.VarChar(64) // "超级管理员" "内容编辑"
  permissions String @db.Text //JSON字符串，存储权限标识数组
  adminUsers  AdminUser[]
}

model AdminLoginLog {
  id            Int      @id @default(autoincrement())
  adminUserId   Int
  loginIp       String   @db.VarChar(128)
  loginResult   Int      //1登录成功；0登录失败
  loginTime     DateTime @default(now())
  adminUser     AdminUser @relation(fields:[adminUserId], references:[id])
}

model BlogArticle {
  id              Int      @id @default(autoincrement())
  title           String   @db.VarChar(255)
  shortDesc       String   @db.Text
  coverType       String   @db.VarChar(32) // "image" 多张图轮播 / "video"视频悬浮预览
  coverImages     String?  @db.Text //json数组存储多张封面图片访问地址
  coverVideo      String?  @db.VarChar(512) //短视频资源地址
  coverVideoFrame String?  @db.VarChar(512) //ffmpeg随机截取静态封面帧
  content         String   @db.LongText //富文本HTML正文
  isRecommend     Boolean  @default(false) //是否首页推荐
  isPublish       Boolean  @default(false) //上下架状态
  sort            Int      @default(0) //首页排序权重，数字越大越靠前
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}
```

## 四、后端核心业务说明

### 4.1 RBAC 权限管控

角色固定两类：

1. **超级管理员**：管理员账号 CRUD、角色管理、登录日志查询、重置密码；博客文章全部操作权限。
2. **内容编辑**：仅博客文章新增、编辑、删除；**禁止访问账号管理模块、登录日志接口；后端守卫拦截接口访问**。

> 
> JWT 设计要点：token payload 只保存 `userId、roleId`；每次接口请求后端实时查询该角色对应的权限列表；不要把完整权限放 JWT 载荷，避免权限变更之后旧 Token 依旧拥有旧权限。

### 4.2 视频上传 & FFmpeg 随机抽帧封面流程

1. 后台管理端上传 mp4 短视频；后端接收文件存入对象存储 MinIO/OSS；拿到视频访问地址。
2. 使用`ffprobe`解析视频，读取视频总时长。
3. 在 `0 ~ (totalDuration‑1)` 区间随机生成抽帧时间点。
4. ffmpeg 执行抽帧命令，输出一张 jpg 封面帧；上传这张截图到对象存储；保存访问地址写入字段`coverVideoFrame`。
5. 返回资源地址保存到博客文章记录。

### 4.3 登录日志逻辑

无论登录成功还是账号密码错误，都写入`AdminLoginLog`，记录登录 IP，登录结果；后台仅超级管理员可以分页查看登录日志；支持按时间筛选。

### 4.4 管理员重置密码

超级管理员可以对其他管理员账号重置密码；重置后后端自动 bcrypt 加密；用户后续登录后可以自行修改个人密码。

## 五、前端门户交互详细说明

### 博客卡片组件（首页核心）

1. **封面类型 = image（多张图片轮切）**

- 默认渲染第一张封面；
- `mouseenter`开启定时器，定时切换数组里面的封面图片；
- `mouseleave`停止轮播，切回第一张封面。

2. **封面类型 = video（短视频悬浮预览）**

- 默认展示后端 FFmpeg 截取的静态帧图片（避免页面直接加载大量视频资源拖慢首页）；
- `mouseenter`：开始加载 video 资源，设置`muted、autoplay`静音自动播放短视频预览；
- `mouseleave`：立刻暂停 video，隐藏视频 DOM，恢复展示静态帧图片；

> 
> **性能优化：hover 之后才去请求加载视频资源；首页列表不预加载全部视频。**

点击卡片跳转路由至文章详情页；详情页渲染富文本正文，可展示正文内嵌图片、视频。
